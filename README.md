# DatçaMis storefront

Bağımsız Next.js uygulaması. Katalog, sepet ve yönetim verisi `datcamis-backend` REST API'sinden gelir.

## Ortam

`.env.example` dosyasını `.env.local` yapın.

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
```

Geliştirme adresi `http://localhost:3010`. Yönetim `/admin/login`.

Storefront krem, koyu yeşil ve altın paleti kullanır. Masaüstünde sol kenar limon, zeytin, badem, yaprak ve beyaz çiçek kompozisyonudur; dar ekranda sadeleşir.
